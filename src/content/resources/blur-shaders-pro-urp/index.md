A small collection of blur post-processing effects for URP: **Gaussian**, **box** and **radial** variants. The repository holds the code of the creator's *Blur Shaders Pro* asset pack, which was discontinued and then made free and MIT-licensed on 20 April 2026. The Asset Store listing remains.

According to the README it supports Unity 2022.3 through 6.3. The creator publishes sibling repositories for the Built-in and HDRP versions of the pack.
